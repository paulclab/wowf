## 3. 검증 완료 핵심 메커니즘 요약 (인게임 실측 반영)
- **스킬별 GCD 적용 여부**:
  - **Off-GCD (글쿨 없음)**: `마법 차단(Counterspell)`, `냉정(Presence of Mind)`, `신비의 마법 강화(Arcane Power)`, 마나석.
  - **On-GCD (1.5초 글쿨 적용)**: **`화염 작렬(Fire Blast)`** (외부 가이드 일부 오기와 달리 라이브 인게임 실측상 다른 스킬들에 1.5초 GCD가 돌아감), `점멸(Blink)`, `비전 작렬`(인게임 스샷 시전 **1.3초** — 가속 15% 버프 유무 재확인 필요 / GCD **1.5초**), `신비한 화살`, `얼음 회오리`, `변이`.
- **`마법봉 발사(!마법봉 발사)` 타이머 및 GCD**:
  - **툴팁 재사용 대기시간**: 마법봉 툴팁에는 `1.3초`가 존재하지 않으며, 노버프(가속 0%) 기준 장착한 마법봉 공격 속도(`1.60초`)에서 선딜레이(`0.50초`)를 뺀 **`1.1초 후 재사용 가능`**으로 표시되고, **가속 15% 버프 적용 시 `0.96초`**(`1.10 / 1.15 ≈ 0.9565초`)로 단축됨.
  - **비대칭 GCD**: 일반 주문(`화염 작렬` 등) 시전 시 `마법봉 발사` 아이콘에는 GCD 시계가 표시되지 않으나(실제 발사는 GCD 후 진행), 반대로 `마법봉 발사`를 직접 쏘면 **마법봉 아이콘 자체에도 쿨타임 시계가 돌고 다른 모든 주문에 1.5초 GCD를 강제 발동**시킴.
  - **본섭 `!` 토글 정상 작동**: 본섭에서는 `!마법봉 발사` 연타 시 사격이 꺼지지 않고 정상 유지됨. 단, `1번(!마법봉 발사)` 사격 중에 `2번(신비한 화살 + !마법봉 발사 매크로)`을 누르면 `신비한 화살` 시전이 기존 마법봉 자동 사격을 강제 해제(OFF)하고 같은 프레임의 아랫줄 `!마법봉 발사`는 `1.1초`(가속 15% 버프 시 `0.96초`) 쿨타임/기존 ON 상태와 겹쳐 무효화되므로 채널링 종료 후 마법봉이 꺼진 상태로 남음.
