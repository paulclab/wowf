# 와우 포에버 출처 및 산출물 관리 규칙

1. **파일 기반 산출물 갱신**: 새로운 인게임 실측 사실(스킬 시전 시간, GCD 여부, 마법봉 속도, 마법부여 숙련도 상승 등)이 확인되면 대화창 답변에만 그치지 않고 즉시 `docs/` 하위 해당 마크다운 문서와 `.agents/skills/wow-forever-guide/references/` 문서를 함께 업데이트합니다.
2. **근거 태그 의무화**: 모든 표와 메커니즘 설명에는 `[✅ 인게임 실측: 파일명]` 또는 `[📘 출처명](URL)`을 명시합니다.
3. **추측성 답변 금지**: 확실하지 않은 클라이언트 내부 동작은 추측해 꾸며내지 않고, 인게임에서 바로 확인 가능한 1단계 검증 방법을 함께 제시합니다.
4. **지명 표기 시 위치 병기 의무**: 모든 가이드 및 답변에서 지역·마을·던전·NPC 지명을 표기할 때는 반드시 **대륙, 상위 지역 내 방향, 좌표(확인된 경우) 및 접근 경로**를 함께 명시합니다 (예: `아스트라나르 [칼림도어 > 잿빛골짜기 중앙 (34.4, 48.0)]`).
5. **던전·숨겨진 입구 상세 동선 표기 의무 (지상 입구 vs 내부 포탈 구분)**: 던전, 동굴, 탑, 수중/지하 시설처럼 **실제 인던 포탈이나 목표가 건물·동굴·수중 터널 내부에 숨어 있는 경우**, 절대 포탈 좌표만 적지 않고 ① **지상/외부 입구 좌표와 지형 특징** + ② **입구에서 포탈까지의 내부 이동 동선(계단·잠수·비인던 몹 동굴·갈림길 등)**을 반드시 함께 안내합니다 (예: `검은심연의 나락` = 조람 해안 신전 폐허 `(14.2, 14.1)` 계단 하강 → 물속 수중 터널 잠수 통과 → 안쪽 동굴 인던 포탈 `(13.4, 12.8)`).
6. **패치노트 최상단 캐릭터 영향 요약 고정**: `docs/01-system/06-patch-notes-kst.md` 및 `dashboard.html`의 패치노트 섹션을 갱신할 때는 반드시 **최상단에 현재 캐릭터(Lv.26 인간 비전 마법사 · 전문/보조기술)에 직·간접적으로 영향을 미치는 중요사항 요약**을 먼저 배치하고 모든 일시를 **KST**로 표기합니다.
7. **퀘스트 정보 작성 시 마법사용 득템 리스트 필수 병기**: 던전 및 주요 퀘스트 가이드를 작성·갱신할 때는 반드시 **해당 던전/연퀘에서 마법사가 노릴 수 있는 퀘스트 보상 및 보스 드랍 득템 리스트**(부위·드랍처·핵심 스탯·착용 가능 여부·현재 장비 대비 가치 비교)를 함께 정리합니다.
8. **애드온 직접 스캔 의무**: 애드온 현황·충돌·추천 질문 시 사용자에게 스크린샷을 요청하지 않고 `C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns` 및 `...\WTF\Account\*\*\폴-최\AddOns.txt`를 직접 스캔하여 `docs/01-system/03-settings-and-addons.md`와 `dashboard.html`에 기록·답변합니다.
9. **단일 통합 대시보드 & GitHub Pages 자동 푸시 원칙**: 대시보드는 **Memphis Edition 단일 파일(`dashboard.html`)**로만 관리하며(`index.html`은 GitHub Pages 진입점), 수정 및 검증 완료 후 **사용자에게 묻지 않고 즉시 커밋 & `git push origin main`하여 GitHub Pages(`https://paulclab.github.io/wowf/`)에 반영합니다.** (Google Drive 등 별도 외부 동기화는 명시적 요청 시에만 수행)
10. **최근 업데이트 메뉴 `N` 뱃지 유지 원칙**: `dashboard.html`에서 특정 메뉴(탭) 내용을 수정·추가할 때마다 `RECENTLY_UPDATED_TABS`에 해당 탭 ID와 변경 요약을 갱신해 사이드바(`.nav-btn`)와 모바일 퀵탭(`.q-pill`)의 **메뉴 제목 우측 위**에 `N` 뱃지가 표시되도록 유지합니다.
