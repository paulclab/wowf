## 1. 몬스터 레벨 · 이름 색상별 경험치 획득 규칙 & 공식 (`ZD` / `Gray Level`)

### A. 핵심 경험치 계산 공식 (`[📘 공식/DB 교차 확인]`)
- **동렙 기본 경험치 (`Base XP`, 아제로스 기준)**:
  $$\text{Base XP} = 45 + 5 \times \text{레벨} \quad (\text{예: Lv.28 동렙 일반 몹} = 185\text{ XP})$$
- **상위 레벨 몹 (`+1 ~ +4`, 상한 `+20%`)**:
  $$\text{XP} = \text{Base XP} \times \Bigl(1 + 0.05 \times \min(\text{MobLv} - \text{CharLv},\; 4)\Bigr)$$
- **하위 레벨 몹 (노랑 하위 `-1~-2` 및 초록 몹)**:
  $$\text{XP} = \text{Base XP} \times \left(1 - \frac{\text{CharLv} - \text{MobLv}}{\text{ZD}}\right)$$
  - *※ 와우 포에버 특이점*: 하위 레벨(초록) 몹 계산 시 `Base XP`에 `CharLv` 대신 **`MobLv`**가 반영되는 이중 감소 보정이 보고되어, 일반 클래식보다 저레벨 초록 몹 구간(`-4` 이하)의 경험치 하락폭이 더 가파릅니다.
- **Zero Difference (`ZD`) 구간표**:
  - `Lv.1~7`: `5` · `Lv.8~9`: `6` · `Lv.10~11`: `7` · `Lv.12~15`: `8` · `Lv.16~19`: `9` · **`Lv.20~29`: `11` *(현재 Lv.28)*** · `Lv.30~39`: `12` · `Lv.40~44`: `13` · `Lv.45~49`: `14` · `Lv.50~54`: `15` · `Lv.55~59`: `16`
- **회색 한계 (`Gray Level`, 이하 처치 시 `0 XP`)**:
  - `Lv.6~39`: $\text{CharLv} - \lfloor \text{CharLv}/10 \rfloor - 5$ → **현재 Lv.28 기준 `Lv.21 이하` 회색 (`0 XP`)!**
  - `Lv.40~59`: $\text{CharLv} - \lfloor \text{CharLv}/5 \rfloor - 1$ *(예: Lv.40 → Lv.31 이하 회색)*

### C. 경험치 획득 불가 (`0 XP`) 케이스 & 상한 (`Cap`) 케이스 총정리
- **경험치 획득 불가 (`0 XP`) 5대 케이스**:
  1. **회색(Gray) 몹 처치**: `MobLv ≤ Gray Level` (현재 Lv.28 기준 `Lv.21 이하`).
  2. **인던 고레벨 동행(12레벨 초과 룰)**: 파티 내 최고레벨 캐릭터가 처치 몹보다 **12레벨 초과(`13레벨 이상` 차이)**일 경우 **파티원 전원 몹 처치 XP `0`** *(단, 던전 퀘스트 반납 XP는 정상 지급 — `11/14~15` 패치 반영)*.
  3. **타인 선점(회색 이름표 / Tap)**: 파티 외 유저가 먼저 타격해 선점된 몹 처치 시 `0 XP` & 루팅 불가.
  4. **경비병/NPC 과다 기여 & 무한 소환 쫄**: NPC 경비병이 피해 대부분을 넣은 몹이나 일부 무한 소환 쫄은 `0 XP`.
  5. **만렙(Lv.60) 도달**: 처치 XP `0` (퀘스트 XP는 골드로 전환).
- **경험치 상한 (`Cap`) 4대 케이스**:
  1. **상위 레벨 몹 보너스 상한 (`+4`레벨 = `+20%`)**: `+5` 이상 빨강/해골을 잡아도 `+20%` 이상 더 주지 않음.
  2. **휴식 경험치(Rested XP) 누적 상한 (`150%` = 30칸 = 1.5레벨)**: 적용 시 몹 처치 XP **`×2.0`(+100%)** — *퀘스트 XP 미적용*.
  3. **야영 텐트 충전 상한 (`5%` = 1칸)**: 현재 휴식 XP가 **5% 미만**일 때만 최대 5%까지 충전 (1시간 쿨).
  4. **버프 적용 범위 상한**: `포만감(+5%)` · `아늑한 침낭(+1~3%)` · `휴식(+100%)`은 **모두 몬스터 처치 XP에만 적용**되며 퀘스트 완료 보상 XP는 증폭되지 않음.

## 2. 인던 경험치 패널티 & 레벨 차이 규칙
- **고레벨 동행(버스) 방지 규칙** `[📘 출처:` [MMOEXP](https://www.mmoexp.com/)`]`:
  - 파티 내에 처치 대상 던전 몬스터보다 **12레벨 이상 높은 캐릭터**가 포함되어 있으면 던전 몹 경험치가 크게 삭감되거나 무효화됩니다.
  - 적정 레벨(예: 26레벨 → `스톰윈드 지하감옥 Lv.24~30`, `검은심연의 나락 Lv.24~32`) 파티로 도는 것이 경험치·아이템 효율 모두 최상입니다.

## 3. 마나 관리 5초 규칙 (5-Second Rule) & 전투 시전 시스템
1. **5초 규칙 (`5SR`) 및 2초 마나 틱** `[📘 출처:` [WarcraftTavern](https://www.warcrafttavern.com/)`]`:
   - 마나를 **실제로 소모하는 주문**을 시전한 순간부터 **5초간** 정신력 기반 기본 마나 재생이 멈춥니다.
   - 마나 재생이 `2초` 주기의 고정 서버 틱(Tick)으로 돌아가기 때문에, 실제로 회복이 다시 시작되기까지는 체감 **`5~7초`**가 걸립니다.
2. **예외(5초 규칙 미초기화)**:
   - **`신비한 정신 집중(Clearcasting — 마나 소모 0)`** 또는 **`화살 탄막` 무료 발동 `신비한 화살`**처럼 **마나를 0 소모한 주문은 5초 규칙을 끊지 않으며**, 마법봉 자동 사격 중에도 5초가 지나면 정신력 회복이 재개됩니다.
3. **MP5 vs 정신력**:
   - 장비의 **`매 5초마다 마나 회복(MP5)`** 옵션은 5초 규칙과 무관하게 전투 시전 중에도 100% 작동합니다.
   - 반면 **정신력**은 기본 상태에서는 5초 규칙 중 정지하지만, 비전 28~34레벨 구간에 **`신비한 명상`(최대 50%) + `마법사 갑옷`(50%)**이 모이면 시전 중에도 정신력 재생을 크게 유지할 수 있습니다.
4. **시전 방해(Pushback) 면역**:
   - 피격 시 시전/채널링 시간이 밀리는 시스템이 있으나, 현재 26레벨 비전 특성의 **`정신 집중 연마(5/5)`**로 **`신비한 화살` 채널링 중 피격 밀림을 100% 방지**하고 있습니다 (`[✅ 인게임 실측]`).
