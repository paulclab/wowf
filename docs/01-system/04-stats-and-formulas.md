## 2. 전투 2차 스탯 & 와우 포에버(`1.60.1`) 통합 규칙

1. **적중 / 극대화 스탯 통합** `[📘 출처:` [ConquestCapped](https://conquestcapped.com/guides/wow-forever/)`]`:
   - 와우 포에버에서는 주문 적중·물리 적중이 하나의 **통합 적중(Hit)**으로, 주문 극대화·물리 치명타가 하나의 **통합 극대화(Crit)**로 합쳐져 장비에 붙습니다.
2. **주문 적중 캡 (Spell Hit Cap)** `[📘 출처:` [Method](https://www.method.gg/wow-forever)`]`:
   - 동레벨 대상: **`4%`**
   - **+3레벨(해골/레이드 보스) 대상: `17%`** *(특성 `정밀함` 등이 있으면 그만큼 차감)*
3. **주문 극대화 피해 배율** `[📘 출처:` [Icy Veins](https://db.icy-veins.com/wow-forever/)`]`:
   - 기본 주문 극대화 시 피해량은 일반 적중의 **`150%`**(1.5배)입니다 *(근접 물리 200%와 다름)*.
4. **주문 가속 (Haste) & 최소 GCD 하한** `[📘 출처:` [Method](https://www.method.gg/wow-forever)`]`:
   - $$\text{적용 시전 시간 / GCD} = \frac{\text{기본 시간}}{1 + \text{가속 비율}}$$
   - **글로벌 쿨타임(GCD) 최소 하한은 `1.00초`**입니다 *(기본 `1.50초` GCD를 `1.00초`까지 줄이려면 가속 `50%` 필요)*.
   - 현재 가속 `15%` 버프 시: 기본 `1.50초` GCD → `1.30초`, `마법봉 발사` 쿨타임 `1.10초` → **`0.96초`** (`[✅ 인게임 실측]`).
5. **저항력 & 주문 관통력 (Spell Penetration)** `[📘 출처:` [Games.gg](https://games.gg/), [ConquestCapped](https://conquestcapped.com/guides/wow-forever/)`]`:
   - 와우 포에버는 고정 구간 저항(25/50/75%) 대신 부드러운 비례 경감 공식을 사용합니다:
     $$\text{평균 피해 경감(\%)} = \left(\frac{\text{유효 저항력}}{5 \times \text{공격자 레벨}}\right) \times 75\%$$
   - `주문 관통력 1` = 대상의 유효 저항력 `1` 감소 *(단, 0 미만 음수로 내려가지는 않음)*.
   - 현재 **`신비한 미묘함(2/2)`**으로 **`주문 관통력 15`**가 스탯창에 상시 적용 중입니다 (`[✅ 인게임 실측: 10 59 05.png]`).
6. **방어도(Armor) 물리 피해 감소 (참고)** `[⚠️ 클래식 표준 공식]`:
   - $\text{물리 경감(\%)} = \frac{\text{방어도}}{\text{방어도} + 400 + 85 \times \text{공격자 레벨}}$ (천 방어구 4부위 `체력+3 / 방어도+24` 키트 4개 = `+96 방어도`로 초반 몹 상대 생존력 체감 상승).
